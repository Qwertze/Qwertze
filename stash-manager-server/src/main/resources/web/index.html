Link addon

  1. In Meteor, open the stash-manager module.
  2. Paste the server-url and the api-key below.
  3. Enable the module with a stash loaded.

One API key works for any number of bots. Give each bot its own stash name (Meteor: stash-sorter's stash-name; proxy: the stash name in the plugin), so their indexes and orders stay apart. A stash name belongs to the first bot that uses it; release it in Bots to hand it to another.
